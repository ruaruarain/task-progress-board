# 看板使用说明

## 这是什么

一套**双读者**的项目状态制品：同一个数据源，产出两种界面。

| 读者 | 产物 | 形态 |
|---|---|---|
| **人**（你 / 负责人 / 领导） | `任务看板.html` | 双击打开，点击展开看细节，一屏看懂进度 |
| **AI agent**（Codex / Claude Code / Cursor / DSH 等） | `AI交接.md` | 纯 Markdown，含待办队列、硬禁忌、可复制命令 |

设计原则：**人看 HTML，AI 看 MD，数据只有一份**。改 `看板数据.json` → 跑一次 `同步.py` → 两个产物同时刷新；`_自检.py` 会校验两者数字一致（改了数据忘重新生成会直接报错）。

## 一、给人看的：`任务看板.html`

**点击任意一行 → 在该行下方按流程顺序展开全部子项。**

### 展开后有两块

**① 流程图（按阶段分列）**

不是一条直线：每个流程的子项按 `阶段` 归到若干列，列与列之间有箭头。

```
┌─ 阶段1 准备 ────┐   ┌─ 阶段2 校验 ─────────┐
│ 依赖清单    W2  │ → │ 数据完整性校验   W4  │
│ ▓▓▓▓▓▓ 100%     │   │ ▓▓▓░░░ 60%           │
│ 数据来源    W3  │   │ 权限与账号      W3   │
│ ▓▓▓▓▓▓ 100%     │   │ ░░░░░░ 0%            │
└─────────────────┘   └──────────────────────┘
```

- **同一列内的子项互不依赖，可以并行**（所以不是一根线）
- **列与列之间才是先后顺序**
- 方块右上角 `W1`~`W5` = 权重：1 普通、2~3 重要、**5 = 决定该模块能否交付**；数字越大越红
- 颜色与进度条同一套：绿=100%、蓝≥70%、黄≥40%、橙=起步、灰=0
- 鼠标悬停方块看该子项说明

**② 子项明细（按流程顺序）**

序号 / 名称（后面跟 `权重 N`）/ 完成度 / 说明 / 📄依赖文件 / 📘说明文档 / ⚠卡点。

### 一键隐藏已完成

每个流程展开区右上角：

```
[ 隐藏已完成 (2) ]  ←→  [ 显示已完成 (2) ]
```

只影响当前流程，切流程/搜索/换筛选都不会丢状态。

### 其他操作

| 操作 | 效果 |
|---|---|
| 双击 `任务看板.html` | 默认浏览器打开，不需要联网、不需要装东西 |
| 顶部状态按钮 | 只看「可用 / 待修 / 阻塞 / 未开始」 |
| 搜索框 | 输关键词，命中子项时会自动展开该流程 |
| `Esc` | 收起全部 |
| 展开后点文件名 | 用默认程序打开该文件 |

## 二、给 AI 看的：`AI交接.md`（自动生成，勿手改）

共 10 节：

| 节 | 内容 | 作用 |
|---|---|---|
| 1 | 五分钟上手（读序 + 一条验证命令） | 不用自己决定先看什么 |
| 2 | 环境事实 | 解释器、编码要求、版本控制 |
| 3 | 常用命令（含期望输出） | 复制即用，能立刻自证环境没坏 |
| 4 | **禁止事项** | 每条带"原因 + 证据文件"，防止 AI 好心办坏事 |
| 5 | 既定结论 | 已经算过的东西别重算 |
| 6 | **待办队列（自动排序）** | 见下 |
| 7 | 改完怎么证明没改坏 | 每条链对应验证命令 + 期望值 |
| 8 | 同步规则 | 明确"不自动同步，要问用户" |
| 9 | 文件索引 | 代码 / 数据 / 文档三类清单 |
| 10 | 进度快照 | 与 HTML 同源的数字 |

### 第 6 节怎么排的

优先级分 = **权重 × 未完成度**，然后分三组：

- **6.1 建议现在先做**：体量为"小" 且 卡点不含外部依赖 → 真正能立刻开工的活
- **6.2 需要专项排期**：体量"大"（≥3 天）→ 别顺手干，会烂尾
- **6.3 ⛔ 卡在外部资源**：要人/要数据/要装东西/要拍板 → 先把资源要到手

## 三、完成度怎么算（重要）

**按子项重要度加权**：`Σ(权重 × 完成度) / Σ权重`。

- 普通环节权重 1；重要 2~3；**决定能否交付的 4~5**
- 目的：避免"30 个子项里 20 个做完了 → 显示 70%"这种虚高。一个权重 5 的环节是 0%，整体就该被明显拉低

**完整度判定**：

| 填什么 | 什么时候可以填 |
|---|---|
| 100 | 有可执行的验证跑过并通过 |
| 70~99 | 主体可用，有明确已知缺口 |
| 30~69 | 部分实现，核心环节还缺 |
| 1~29 | 起了个头或有致命错误 |
| 0 | 完全没做或卡在外部资源 |

## 四、怎么同步

```powershell
$env:PYTHONIOENCODING='utf-8'
"${PY}" -X utf8 "${看板目录}/同步.py"
```

它会：**数据体检 → 生成两个产物 → 自检（含两者快照数字一致）**。
退出码 0 且末行 `✅ 同步完成，一切一致` 才算成功。

体检会拦住：完整度超范围、权重非法、缺阶段、路径用反斜杠或不存在、**100% 还挂卡点**、**未完成却说不清"还差什么"**、重名、`AI接手` 缺节。

| 模式 | 用途 |
|---|---|
| `同步.py` | 完整流程（默认） |
| `同步.py --check` | 只校验不生成 |
| `同步.py --lint` | 只体检 |
| `同步.py --quick` | 生成 + 自检，跳过体检 |

## 五、JSON 字段含义

```jsonc
{
  "标题": "示例项目 · 进度看板",
  "项目根": "../..",            // 可选：文件/文档路径相对的根；不写则自动向上找 .git / AGENTS.md
  "流程": [
    {
      "id": "B",                 // 短代号
      "名称": "B 核心功能",        // 表格主标题
      "一句话": "这条流程决定产品能不能用",
      "状态": "待修",             // 可用 / 部分可用 / 待修 / 阻塞 / 未开始
      "部分": [                  // **数组顺序 = 明细顺序 = 待办来源**
        {
          "名称": "主流程实现",
          "完整度": 100,
          "说明": "主流程可跑通，自测断言 42 条全部通过",
          "卡点": "可选：缺谁/缺什么",
          "权重": 5,
          "体量": "中",            // 大 / 中 / 小
          "阶段": "实现",          // 流程图按它分列
          "文件": ["${看板目录}/示例/进度记录.md"],
          "文档": []
        }
      ],
      "卡点": ["这条链的整体卡点"],
      "更新": "2026-11-23"
    }
  ],
  "AI接手": {                    // 驱动 AI交接.md 的 1~10 节
    "读序": [], "环境": {}, "常用命令": [], "禁止事项": [],
    "既定结论": [], "验证归属": [], "同步协议": [],
    "延伸阅读": [],              // 可选：生成 MD 结尾的"更细步骤去哪读"
    "检查项": {"根目录AGENTS": "warn"}   // fail / warn / off
  }
}
```

**三点注意**
- 路径写**相对项目根**、用 `/` 分隔，生成时自动转成相对 HTML 的链接
- JSON 不能有多余逗号；改完直接跑同步，报错会指到行
- `状态` 只能用那 5 个词

## 六、文件清单

| 文件 | 作用 |
|---|---|
| `看板数据.json` | 唯一数据源 |
| `生成看板.py` | 生成器：JSON → HTML + MD，并按权重算完成度 |
| `同步.py` | 标准执行器：体检 → 生成 → 自检 |
| `_自检.py` | 产物自检（结构 / 章节 / 快照一致） |
| `_验收_lint.py` | 体检自测（故意造 8 类违规，确认都拦得住） |
| `_验收_看板.py` | 版面自测（阶段覆盖 / 流程图 / 权重徽标） |
| `任务看板.html`、`AI交接.md` | 产物，勿手改 |
| `.dsh/skills/`（初始化时生成） | 两个技能：`progress-sync`、`board-maintain` |

## 七、设计意图

```
          看板数据.json  ← 唯一数据源
                │  同步.py = 体检 + 生成 + 自检
      ┌─────────┴─────────┐
      ▼                   ▼
 任务看板.html         AI交接.md
（人：点击展开）    （AI：队列/禁忌/命令）
      └────► _自检.py ◄──┘
          校验两者数字一致
```

- **标准**在技能里（可评审、可版本化、AI 会自动加载）
- **执行**在一个脚本里（确定性、有退出码、能被 CI 调用）
- **产物**自动生成（不给人留"手改一处忘记另一处"的机会）
- **防退化**：`_自检.py` 校验结构，`_验收_lint.py` 校验体检本身有效
