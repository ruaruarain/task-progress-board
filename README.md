# 任务进度看板工具包

> **English TL;DR** — A double-audience project board: one JSON data source generates two artifacts — a
> single-file HTML board (click a row to expand sub-items grouped into parallel stages, with weights and
> a "hide completed" toggle) and a Markdown handoff doc for AI agents (auto-sorted backlog, hard rules,
> copy-paste commands). Includes a generator, a sync orchestrator, a data linter, self-checks, and two
> agent skills. Local-only, no server, no dependencies beyond Python 3.10+.

**给「人多、事杂、还有人/AI 要接手」的项目用的一张小看板。**

一份 JSON 数据源 → 两个产物：

- **`任务看板.html`** —— 双击就能打开，一屏看完所有流程；点开一条流程，先看到**按阶段分列的流程图**（同一列的子项互不依赖、可并行），再看到逐条明细（完成度 / 权重 / 说明 / 依赖文件 / 文档 / 卡点）
- **`AI交接.md`** —— 纯 Markdown，给 AI agent 用：自动排好序的待办队列、硬禁忌（带证据）、可复制命令、改完怎么自证

同步只要一条命令，它同时做**数据体检 → 生成两个产物 → 自检（含两者数字一致）**。

---

## 它解决什么问题

**没有看板时**：进度散在聊天记录、口头汇报、几个 Excel 里。你问"现在到哪了"，得到的是一段含糊的叙述；AI 接手时要从零读代码。

**有了它之后**：

| 场景 | 你得到什么 |
|---|---|
| 自己看 | 一屏知道哪条链卡着、哪个子项是"坏了就不能交货"的（权重 5） |
| 汇报 | 点开一条流程，直接念子项和完成度；有卡点的地方写着"缺谁/缺什么"，不用现编 |
| 交接给 AI | 让它读 `AI交接.md`，里面有"现在做什么（已排序）/ 不许做什么 / 改完怎么自证" |
| 防虚高 | 完成度按权重加权，一个权重 5 的环节是 0%，整体分会明显掉下来，糊不过去 |

## 三个不常见但很关键的设计

1. **同一列 = 可以并行的子项**。流程图不是一条线：子项先归到"阶段"，同阶段的画在同一列、列间有箭头。这样"两个子项互不依赖"和"两个子项有先后"在视觉上是分开的。
2. **完成度是加权平均**：`Σ(权重 × 完成度) / Σ权重`。权重 5 = 决定该模块能否交付。目的就是让"重要但没做"的东西无法被平均掉。
3. **体检有牙齿**：`同步.py` 会拦住"100% 却还挂着卡点""未完成却说不清还差什么""路径写成绝对盘符""缺阶段"等。不合格直接不生成。

## 三步用起来

需要 Python 3.10+（不用装任何第三方库）。

```powershell
# 1) 安装到你的项目（会在 <项目>/docs/看板 落盘，并装两个技能到 <项目>/.dsh/skills）
python -X utf8 初始化.py --目标目录 D:\my-project

# 2) 改数据：把 看板数据.json 里的示例流程换成你自己的
#    字段规范见 <项目>/docs/看板/看板使用说明.md

# 3) 生成看板
cd D:\my-project
python -X utf8 "docs/看板/同步.py"
# 然后双击 docs/看板/任务看板.html
```

想换个位置放看板：`--看板子目录 docs/看板`。
目标位置已有 `看板数据.json` 时脚本会拒绝覆盖（防止冲掉已填进度），确实要覆盖加 `--强制`。

## 目录结构

```
.
├── 初始化.py                 # 安装到任意项目（含占位符替换、项目根推导、技能安装）
├── 自测.py                   # 在临时目录（中文+空格）跑全链路，证明包可用
├── 技能模板/
│   ├── progress-sync/        # 「同步进度」的标准（四阶段、字段规范、完成度判定）
│   └── board-maintain/       # 「改看板结构」的标准（加子项、权重尺度、改生成器）
└── 模板/
    ├── 看板数据.json          # 示例：3 条流程 / 12 个子项（覆盖阶段、权重、卡点、100%）
    ├── 生成看板.py            # JSON → HTML + MD，按权重算完成度
    ├── 同步.py                # 体检 → 生成 → 自检（一条命令）
    ├── _自检.py               # 产物自检（结构 / 章节 / 快照一致）
    ├── _验收_lint.py          # 体检自测（造 8 类违规，确认都拦得住）
    ├── _验收_看板.py          # 版面自测（阶段覆盖 / 流程图 / 权重徽标）
    ├── 看板使用说明.md         # 给使用者的完整说明书
    └── 示例/                  # 占位文件，演示"依赖文件/文档"怎么指
```

## 两个技能（给 AI 用的标准）

`初始化.py` 会把它们装到 `<项目>/.dsh/skills/`：

| 技能 | 什么时候加载 |
|---|---|
| `progress-sync` | 用户明确要求同步时：采集证据 → 录入 JSON → 生成 → 验收 |
| `board-maintain` | 用户要求改看板结构时：加减流程/子项、调权重/体量、改生成器、迁机器 |

- **DSH** 会自动加载 `.dsh/skills/`，直接生效
- **Codex / Claude Code / Cursor** 没有这个约定也没关系：让 agent 直接读两个 `SKILL.md`，标准是同一份

两个技能的触发词都写成「**只在用户明确要求时执行**」——同步不会被 agent 自作主张触发。

## 自测

```powershell
python -X utf8 自测.py
```

它会在 `%TEMP%\看板包自测 …\示例项目 带空格\` 里跑：初始化 → 同步 → 断言退出码/末行/产物/快照一致，
并静态扫描"模板里有没有绝对盘符、有没有不该出现的专有词"。当前 **14 项检查全通过**。

> 可选：把 `本机校验词表.example.txt` 复制成 `本机校验词表.local.txt`（已被 `.gitignore` 排除），
> 一行一个填入你项目的内部名称，自测就会额外拦截"把内部信息带进公开产物"的手滑。

## 不适合什么

- **不适合替代 Jira / Linear**：这是"一个人或小团队 + AI 助手"的轻量看板，不是协作平台（没有账号、没有评论、没有通知）
- **不适合 500+ 子项的大项目**：500 个子项是这个看板的实测上限，再多建议拆成多个看板
- **依赖诚实填数**：体检能拦住自相矛盾（100% 还挂卡点、说不清还差什么），但拦不住"你骗自己"。所以 `progress-sync` 里写死了"100% 必须有可执行的验证"

## 已知取舍

- **单文件 HTML**：不依赖任何前端框架/服务，断网可用；代价是没有多用户协作
- **不给看板加权限**：谁拿到文件夹谁就能改 JSON；靠 git 追溯
- **中文优先**：界面与文档都是中文；代码里没有硬编码语言，改文案即可本地化
