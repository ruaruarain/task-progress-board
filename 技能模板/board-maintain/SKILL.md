# 看板维护（board-maintain）

`progress-sync` 管"改数字"，本技能管"改结构"：加流程、加子项、调权重/体量、改生成器、改自检、迁机器。

**先记住不变式**：数据只有一份（`看板数据.json`），产物有两个（`任务看板.html`、`AI交接.md`）。
任何结构改动都必须让两个产物同时正确，并且 `_自检.py` 通过。

> 区分两件事，别把自己卡死：
> - **构建**（改版面、改生成器/自检、加字段/阶段）→ 可以直接跑 `生成看板.py`，这是"把改动落地"。
> - **同步进度**（改 `完整度` / `说明` / `卡点`）→ 属于用户决定节奏，必须**先问再跑**。

## 文件角色

| 文件 | 角色 | 能不能手改 |
|---|---|---|
| `看板数据.json` | 唯一数据源（流程 / 子项 / 权重 / 体量 / 阶段 / `AI接手` 区块） | ✅ 只能改这个 |
| `生成看板.py` | 生成器：JSON → HTML + MD，并按权重算完成度 | ✅ 结构性改动时才改 |
| `同步.py` | 标准执行器：体检 → 生成 → 自检 | ✅ 只在改体检规则时动 |
| `_自检.py` | 产物自检 + 快照一致性 | ✅ 新增检查项时动 |
| `_验收_lint.py` | 体检机制的自测（故意造违规，确认都拦得住） | 改体检后必跑 |
| `_验收_看板.py` | 版面自测（阶段覆盖、流程图钩子、权重徽标） | 改版面后必跑 |
| `任务看板.html` / `AI交接.md` | 产物 | ❌ 永不手改 |

## 加一个子项

1. 在目标流程的 `部分` 数组里，按**你想让读者看到的顺序**插入对象（顺序 = HTML 明细顺序 = MD 待办来源）
2. 必填 `名称` / `完整度` / `说明` / `阶段`
3. 未完成时写 `卡点`，或在说明里写"还差：…"
4. 判断 `权重`（1~5）与 `体量`（大/中/小），规则见 `progress-sync`
5. `文件` / `文档` 写相对项目根、用 `/` 分隔、必须真实存在
6. 跑 `同步.py`，体检与自检都要过

## 加 / 删一条流程

- 流程字段：`id`（短代号，如 `D`）、`名称`、`一句话`、`状态`、`部分[]`、`卡点[]`、`更新`
- `状态` 只能是：`可用` / `部分可用` / `待修` / `阻塞` / `未开始`
- **不要手写流程级 `完整度`**：它由生成器按 `Σ(权重×完成度)/Σ权重` 算出来，手写会被覆盖
- 删流程时检查 `AI接手.验证归属` 里是否还引用它

## 阶段（流程图的分列依据）

- 同一 `阶段` 的子项会被画在**同一列**，表示"互不依赖、可并行"
- 阶段之间按子项首次出现的顺序从左到右排列，表示先后
- 子项很多时，阶段数 3~6 个最易读；只有 1 个阶段时体检会给警告（流程图会退化成一条线）

## 权重与体量的尺度

| 权重 | 含义 | 判断问句 |
|---|---|---|
| 5 | 决定该模块能否交付 | "这一项坏着，整个模块的数字还能用吗？" 不能 → 5 |
| 4 | 关键但可绕过 | 有替代路径，但代价大 |
| 3 | 重要环节 | 影响质量，不影响能否交付 |
| 2 | 次要 | 打磨类 |
| 1 | 普通 | 默认 |

| 体量 | 含义 | 与待办队列的关系 |
|---|---|---|
| 大 | ≥3 天，或需要专项排期 | 只进 6.2「需要专项排期」，**不进**"建议现在先做" |
| 中 | 半天~2 天 | 小活清空后才会被推荐 |
| 小 | 半天内 | 优先推荐 |

## 改生成器的规矩

1. 改完必须跑：`生成看板.py` → `_自检.py` → **`node --check` 校验 JS**
   ```powershell
   $node = "node"; # 或本机 node 的完整路径
   & $node --check "${看板目录}/_check.js"   # _check.js 由 _自检.py 导出
   ```
2. HTML 里所有动态文本必须走 `esc()` 转义
3. 新增 DOM 结构时，在 `_自检.py` 里加一条存在性检查
4. 新增数据字段时，在 `同步.py` 的 `lint()` 里加取值校验，并给默认值（老数据不能因此崩）

## 体检规则的优先级

**错误**只给"会让读者/AI 判断错"的问题（完成度虚高、100% 还挂卡点、路径不存在、状态非法、重名、缺阶段）；
措辞、格式等建议性问题放**警告**。

## 迁移到新机器

1. 整目录拷过去（含 `.dsh/skills/` 与看板目录）
2. **不要改代码里的路径**：`PROJECT_ROOT` 会自动向上找 `.git` 或 `AGENTS.md`
3. 若看板放在非默认深度，在 `看板数据.json` 顶层加 `"项目根": "../.."`（相对看板目录）
4. 跑 `同步.py --check` 确认体检通过，再跑一次完整 `同步.py`

## 别做这些

- ❌ 在 `任务看板.html` 里直接改文字（下次生成被覆盖）
- ❌ 让 `AI交接.md` 变成手工维护的第二数据源（两份必然漂移）
- ❌ 把流程级 `完整度` 手写进 JSON（会被加权计算覆盖）
- ❌ 为了"看起来进度高"调权重——权重是技术判断，不是修辞
